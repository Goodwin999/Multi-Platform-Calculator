# 🧮 Кросс-платформенный Калькулятор

## 📋 Описание проекта
Современный калькулятор с **единой логикой вычислений** и разными интерфейсами. Написал once - запускай где угодно!

## 🎯 Функционал
- ✅ **Базовые операции** (+, -, *, /)
- ✅ **Веб-версия** (Spring Boot + Thymeleaf)
- ✅ **Десктоп-версия** (JavaFX)
- ✅ **Кросс-платформенность** (Windows, Linux, macOS)
- 🔜 **Расширенные функции** (научные, память)
- 🔜 **Мобильная версия** (Android)
- 🔜 **PWA поддержка**

## 🛠 Стек технологий
- **Backend**: Java 21, Spring Boot 3.5.7
- **Десктоп**: JavaFX 21
- **Веб**: Thymeleaf, Bootstrap
- **Сборка**: Maven, Multi-модульная архитектура
- **Контейнеризация**: Готовность к Docker

## 🏗 Архитектура
```
calculator-app/
├── 📦 calculator-core      # Общая логика вычислений
├── 🌐 calculator-web       # Веб-интерфейс (Spring Boot)
├── 💻 calculator-desktop   # Десктоп приложение (JavaFX)
└── 🔜 calculator-mobile    # Будущее: Android версия
```

## 🚀 Масштабируемость
- **Модульная архитектура** - легко добавлять новые платформы
- **Готовность к микросервисам** - можно разделить на отдельные сервисы
- **Cloud-native** - совместимость с Docker & Kubernetes
- **Расширяемое ядро** - подключаемая система операций

## 📦 Быстрый старт
```bash
# Запуск веб-версии
mvn spring-boot:run -pl calculator-web

# Сборка десктоп приложения
mvn package -pl calculator-desktop
```

## 🎯 Применение
- Изучение кросс-платформенной разработки
- Корпоративное решение для вычислений
- Сравнение UI на разных платформах
- Пример модульной архитектуры
